# Workflow Reference

Use this reference for complex transformations, open-source packaging, or multi-output planning.

## Value Score

Give a quick score from 1-5 for each dimension:

| Dimension | 1 Point | 5 Points |
|---|---|---|
| Surprise | Common recap | Fresh or counterintuitive |
| Usefulness | Interesting but vague | Gives a method, decision, or action |
| Creator fit | Anyone could say it | This creator can say it credibly |
| Platform fit | Wrong format | Naturally fits the platform |
| Asset value | One-off line | Can become a series, product, or knowledge card |
| Risk control | Easy to misquote/copy | Easy to paraphrase and attribute |

Recommendation:

- 24-30: Strong, create publishable content.
- 17-23: Medium, create card and angles first.
- 6-16: Weak, archive as raw inspiration.

## Output Decision

| If The Idea Has | Best Output |
|---|---|
| A sharp misconception | Short video script |
| Several practical points | Xiaohongshu note or checklist |
| Many related branches | Topic bank |
| One strong sentence but little context | Insight card |
| A strong audience question | Comment/DM prompt |
| A reusable method | Knowledge-base card |
| A productizable workflow | Guide/product angle |

## Script Template

```text
开头：我听到/看到一个观点，第一反应是...
反常识：以前我以为...但这个观点提醒我...
个人转译：这和我最近在做的...很像。
解释：普通人可以这样理解...
方法：下次遇到这种情况，先做这 1-3 步...
CTA：如果你也遇到...可以在评论区告诉我...
```
