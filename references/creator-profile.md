# Simple Creator Profile

Use a profile that a beginner can fill in quickly. Accept phrases, keywords, or "not sure yet". Never block the task because a field is incomplete.

## Minimal Fields

| Field | Plain Meaning | If User Is Unsure |
|---|---|---|
| Creator positioning | "Who am I in this content?" | Infer from their bio, topic, or first-person notes |
| Platform | Where this will be published | Default to the platform they mention; otherwise ask only if format matters |
| Content field | What topics I usually talk about | Infer from keywords and current request |
| Voice style | How I sound when I talk | Use "plain, useful, personal" as fallback |
| Target audience | Who should feel this is for them | Infer from pain points |
| Goal | What this content should help achieve | Default to trust-building, not hard selling |
| Avoid | What I do not want to sound like or discuss | Avoid exaggeration, plagiarism, fake data, and generic AI tone by default |
| CTA | What I want people to do next | Default to comments, saves, follows, or "tell me your case" |

## Fillable Template

```text
创作者定位：
平台：
内容领域：
表达风格：
目标用户：
商业目标：
禁用表达：
常用 CTA：
```

## Beginner-Friendly Intake

If the user has no profile, ask for at most 3 of these:

1. 你主要想发在哪个平台？
2. 你希望别人把你记成一个什么样的人？
3. 这条内容想带来什么：流量、信任、收藏、私信，还是产品转化？

If the user wants immediate output, infer a working profile and include a short "我先按这个画像处理" note.
